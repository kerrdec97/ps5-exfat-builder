exFAT Image Builder
===================

Run "exFAT Image Builder.exe".

There are two editions of the same program:
* The single exe (exFAT.Image.Builder.exe) unpacks this folder on its first
  start into %LOCALAPPDATA%\kerrdec97\exFAT Image Builder\runtime.
* The folder edition (exFAT-Image-Builder-<version>-win64-folder.zip) is this
  folder as it is: extract the zip anywhere, for example on an external
  drive, and run the exe inside. Nothing is unpacked. Choose it when your
  antivirus removes the single exe.

* Settings, history and the queue are stored in your user profile
  (%APPDATA%\kerrdec97\exFAT Image Builder Farewell). To keep everything next
  to the program instead, create an empty file named portable.txt next to
  the exe you start (for the single exe: the file you downloaded, not its
  unpacked copy); data then goes to a "data" folder beside it, and the single
  exe unpacks into "exFAT Image Builder.data" beside it.
  Settings > Storage shows every folder the app uses.
* Logs: %LOCALAPPDATA%\kerrdec97\exFAT Image Builder Farewell\logs
  (or data\logs in portable mode). Logs page > Open log folder.
* Sony Publishing Tools are not part of the published program. FPKG builds
  use your own copy; point Settings > Tools at it.
